# Claims A9, A10 — SaverPacific US and NZ origin pages (background only)

**Date checked:** 2026-09-09

Background/comparator context only per CLAIMS.md section A. Not a collection target now or
ever.

## Method

1. Fetched saverpacific.com homepage, grepped nav links for origin-country patterns.
2. Probed guessed URL slugs for NZ/US origin pages directly (HTTP status only).
3. Fetched `wp-sitemap.xml` (sitemap index) and `wp-sitemap-posts-page-1.xml` (the WordPress
   "page" post-type sitemap) to get an authoritative page list rather than relying on nav-menu
   guesses.
4. WebFetch of the NZ origin page content for destinations/comparison widget.
5. Brief check of plausible alternate US domains/subdomains — done lightly, not pursued
   deeply, since this is background context only.

## Evidence

### Page sitemap (`https://saverpacific.com/wp-sitemap-posts-page-1.xml`)

Only three relevant URLs listed:

```
https://saverpacific.com/send-money-from-australia/
https://saverpacific.com/send-money-to-australia/
https://saverpacific.com/send-money-from-new-zealand/
```

No `send-money-from-usa`, `send-money-from-united-states`, or similar in the sitemap.

### Direct URL probes (HTTP status)

```
send-money-from-new-zealand      -> 200
send-money-from-nz               -> 404
send-money-from-usa              -> 404
send-money-from-united-states    -> 404
send-money-from-us               -> 404
```

### Alternate domain probe

`us.saverpacific.com` and `saverpacificusa.com` did not resolve/respond (curl exit indicating
no connection, reported as `000`). `saverusa.com` returned HTTP 200 but the fetched body
contained no "Saver" or "SaverPacific" branding in the title/content grep — appears to be an
unrelated domain, not part of the Saver Global family. Not pursued further; this is a dead
end, noted so it isn't silently re-tried later.

### NZ origin page content (`https://saverpacific.com/send-money-from-new-zealand/`)

Heading: "Send Money From New Zealand – SaverPacific." Comparison widget present with
"Country from," "Country to," "How much" (NZD) fields and a "Compare" button — same pattern as
the AU page (A5/A6).

Destinations listed: Cook Islands, Fiji, Kiribati, Niue, Samoa, Solomon Islands, Timor Leste,
Tonga, Tuvalu, Vanuatu — **ten**, matching the AU page's count (A7) but not necessarily the
same set (Timor Leste appears here; PNG is absent here as it was on the AU page).

## Conclusion

**A10 (NZ origin page exists) — proposed status: VERIFIED.** The page exists, is live, and
lists ten Pacific destinations with a working-looking comparison widget (fields present;
functional behaviour of the "Compare" button itself was not exercised, since we are not
interacting with SaverPacific beyond a read).

**A9 (US origin page exists) — proposed status: REFUTED.** No US-origin page appears in
SaverPacific's own sitemap, and every plausible URL slug returned 404. Combined with the
earlier finding that Saver Global reportedly runs six regional sites (A8), the US likely has
its own separate site under a different domain rather than a `saverpacific.com` subpage — but
I did not find that domain. Absence of a `saverpacific.com` US page is well evidenced;
non-existence of *any* Saver Global US-origin service anywhere is not established and I am not
claiming it.

## Confidence flag

I did not exhaustively search for a possible separate US-specific Saver Global domain beyond
three guessed names. If a US-origin Saver Global site exists under an unguessed domain, this
finding would miss it. Given this is explicitly background-only context (not a collection
target), I did not think a fuller domain search was worth the additional requests, but flagging
so the "REFUTED for saverpacific.com" framing isn't over-read as "SaverPacific has no US
service anywhere."
